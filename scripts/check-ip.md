## Что делает скрипт

| Проверка | Что проверяет | Критичность |
| :--- | :--- | :--- |
| **1. Геолокация** | Страна, город, организация, timezone через `ipinfo.io` | ✅ OK / ⚠️ WARN / ❌ FAIL |
| **2. DNSBL** | 11 публичных чёрных списков (Spamhaus, Barracuda, SORBS, UCEPROTECT и др.) | ❌ FAIL при попадании |
| **3. Scamalytics** | Fraud Score — даёт ссылку для ручной проверки (API закрыт) | 🔗 Ручная |
| **4. AbuseIPDB** | Confidence of Abuse + отчёты (если задан `ABUSEIPDB_API_KEY`) | ❌ FAIL при ≥75% |
| **5. Сеть** | Ping, TCP 443, DNS-резолвинг `api.anthropic.com` | ⚠️ WARN при проблемах |

## Использование

```bash
# Сделать исполняемым
chmod +x check-ip.sh

# Проверить внешний IP хоста (на котором запущен скрипт)
./check-ip.sh

# Проверить конкретный IP VPS
./check-ip.sh 203.0.113.42

# С AbuseIPDB (получите ключ на https://www.abuseipdb.com/register)
ABUSEIPDB_API_KEY=your_key ./check-ip.sh 203.0.113.42

# JSON для автоматизации
./check-ip.sh --json 203.0.113.42

# Быстрая проверка без DNSBL (только гео + ping)
./check-ip.sh --no-dnsbl 203.0.113.42
```

## Exit codes

| Код | Значение |
| :---: | :--- |
| `0` | Все проверки пройдены — IP готов |
| `1` | Есть предупреждения — мониторьте |
| `2` | Критические проблемы — пересоздайте VPS |
| `3` | Ошибка аргументов или окружения |

## Соответствие шагу 1.2 из `vps-setup.md`

Скрипт автоматизирует **шаг 1.2** («Проверка чистоты IP-адреса»):
- DNSBL — автоматически (11 списков).
- AbuseIPDB — автоматически (если задан ключ).
- Scamalytics — даёт прямую ссылку `https://scamalytics.com/ip/<IP>` для ручной проверки (публичного API нет).
- Дополнительно — ping и TCP 443 для проверки доступности VPS.

## Замечания по зависимостям

- `bc` используется только для сравнения ping с порогом; если не установлен — сравнение тихо пропускается.
- `grep -P` (PCRE) требует GNU grep — на macOS может понадобиться `brew install grep` или замена на `-oE`.
- На минимальных системах (Alpine) может не быть `dig` — используется fallback `host` / `nslookup` / пропуск.
